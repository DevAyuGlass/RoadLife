# RoadLife

**RoadLife** — проект симулятора автомобилей и игрового движка с открытым исходным кодом. Цель проекта — создать единую игровую среду для настольных и мобильных платформ. Многопользовательский режим планируется на более позднем этапе разработки.

Сейчас проект находится на ранней стадии разработки движка. Для настольных систем используется рендерер на OpenGL 4.2, а поддержка мобильных платформ развивается отдельно.

## Текущие возможности

- Приложение и оконная подсистема на SDL3
- Кодовая база на C++20 и система сборки CMake
- Свободная камера разработчика с нормализованным движением, ускорением и настройкой скорости/телепортации во время работы
- Рендерер OpenGL с абстракциями шейдеров и мешей
- Отображение теней с возможностью включения и выключения во время работы
- Процедурное небо, солнце и цикл дня и ночи с быстрым переключением времени суток
- Туман по расстоянию с настройкой плотности во время работы
- Переключаемые сетка земли и каркасный режим
- Создание и удаление кубов во время работы (до 2 000 объектов сцены)
- Консоль разработчика с историей команд, автодополнением, информацией о состоянии и настройками движка
- Кэширование расположения uniform-переменных шейдеров и вычисление матрицы нормалей на CPU для сокращения лишних операций

## Консоль разработчика

Открыть консоль можно клавишей **F1** или **~**.

Полезные команды:

```text
help
status
camera
camera speed 12
camera teleport 0 3 8
camera reset
wireframe on
fog density 0.02
shadows off
grid off
spawn cube 5 0 -4 1.5
objects
objects clear
time noon
time sunset
```

Удерживайте **Shift**, чтобы ускорить свободное перемещение камеры. Нажмите **Esc**, чтобы освободить или снова захватить мышь.

## Сборка в Arch Linux

Установите необходимые зависимости:

```bash
sudo pacman -S --needed base-devel cmake ninja sdl3 sdl3_ttf glm libepoxy mesa
```

Сконфигурируйте проект и соберите его:

```bash
cmake -S . -B build -G Ninja
cmake --build build
```

Запуск в сессии X11:

```bash
SDL_VIDEODRIVER=x11 ./build/RoadLife
```

Текущий настольный рендерер запрашивает контекст OpenGL 4.2 Core. Для запуска нужен совместимый графический драйвер.

## Структура проекта

```text
Engine/
├── Camera/       # Камера разработчика
├── Console/      # Встроенная консоль разработчика
├── Core/         # Жизненный цикл приложения и работа со временем
├── Platform/     # ОС, окна и интеграция ввода
├── Renderer/     # Графические ресурсы и рендеринг
└── World/        # Сцена и симуляция игрового мира
```

## Планы разработки

1. Разделить жизненный цикл приложения, управление временем, окнами и вводом.
2. Определить независимый от конкретного API графический интерфейс.
3. Добавить графические бэкенды для настольных и мобильных платформ.
4. Реализовать физику автомобилей, управление, звук и потоковую загрузку мира.
5. Разработать конвейер ресурсов, инструменты и документацию для создания контента.
6. Спроектировать архитектуру многопользовательской игры с режимами host/client и выделенным сервером.

## Android (сборка только через терминал)

Для Android предусмотрена отдельная конфигурация сборки на базе SDL3, OpenGL ES 3.0, Android NDK и Gradle. На данный момент целевая архитектура — `arm64-v8a`.

### Требования

- Android SDK: Platform 36 и Build Tools 36
- Android NDK 28.2.13676358
- CMake 3.31.6 (можно установить через SDK Manager)
- Java 17 или новее
- `curl` и `unzip`
- Устройство с поддержкой OpenGL ES 3.0

Скрипт первой сборки загружает официальный Android AAR SDL3 3.4.16 и дистрибутив Gradle 8.13. При конфигурации CMake также загружает GLM 1.0.1.

Из корня репозитория выполните:

```bash
bash scripts/build-android.sh
```

Готовый APK должен появиться здесь:

```text
build-android/apk/RoadLife-debug.apk
```

Чтобы собрать, установить и запустить приложение на подключённом устройстве:

```bash
bash scripts/install-android.sh
```

Либо установите APK вручную:

```bash
adb install -r build-android/apk/RoadLife-debug.apk
adb shell monkey -p com.devayuglass.roadlife 1
```

### Возможности Android-версии на текущем этапе

- Интеграция Android Activity и нативного жизненного цикла через SDL3
- Путь рендеринга на OpenGL ES 3.0
- Та же базовая сцена: камера, освещение, туман, меши и симуляция объектов
- Сенсорное управление: движение при касании левой части экрана и обзор при перемещении пальца по правой части
- Поддержка SDL-геймпадов, если Android распознаёт совместимый контроллер

Настольная консоль разработчика пока не включена в Android-сборку. Каркасный режим, использующий desktop-only polygon mode, также отключён, поскольку этой функции нет в OpenGL ES 3.0. Android-приложение запускается в полноэкранном альбомном режиме.

### Решение проблем при сборке Android

- Если Gradle сообщает, что версия Java слишком старая, установите или выберите JDK 17 либо новее.
- Если CMake не может найти SDL3, удалите каталог `android/app/.cxx` и запустите сборку повторно. Официальный SDL3 AAR должен находиться в `android/app/libs`.
- Если Android SDK или NDK установлены в нестандартном месте, задайте переменные окружения `ANDROID_HOME` и `ANDROID_NDK_HOME`.
- Для просмотра нативных логов используйте `adb logcat`.
